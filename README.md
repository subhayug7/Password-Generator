# Password Generator

A simple Python-based Password Generator that creates random passwords using letters, numbers, and special characters.

## Features
- Generates random passwords.
- Supports customizable password length.
- Uses letters, numbers, and special characters.

## Technologies Used
- Python
- Random Module

## How to Run
1. Clone the repository.
2. Open the project folder.
3. Run:

```bash
python password_generator.py
```
